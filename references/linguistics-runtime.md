# Linguistics runtime (load this, not the monograph)

One page the production loop should keep in working memory.

1. Act = two-second VP*. Mark that node.
2. PHS form: `When [real CUE], already /ACT/`.
3. Grice: if `but not ACT` is sane, you wrote a hint. Rewrite.
4. Karttunen: root/hole yes. *said/dream/story* = plug. *if* = filter only.
5. Gazdar: potential P dies if it clashes with *maybe/said*.
6. Heim/Kamp: tale is an inner file/box. Story-*it* dies when the box closes.
7. van der Sandt: last image = antecedent in the tale; PHS = bind on the global DRS.
8. Geurts: `if you happen to…` is too weak. Use *when*.
9. RT: cheapest stop must be the marked act, not “nice voice.”
10. Two triggers per line. Not five.

Theory files stay on disk for teaching. Runtime uses this card.
