# Arabic MSA Delivery

When the user writes Arabic, write the entire spoken script in clear Modern Standard Arabic. No Egyptian dialect. No slang.

- WPM target: 90–105
- Add 1s to every English-equivalent pause
- Numbers: عشرة... تسعة... with (pause 3s)
- Prefer short verbs: تلاحظ · تسمح · يدع · يستقر · ينزل · يتسع
- Marks: و /تترك الكتفين يسقطان/
- Emergence 1–5 in Arabic. Short loop 8–12 lines Fus'ha.
