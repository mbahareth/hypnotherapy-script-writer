# Combination and Case-Match Protocol

Run this before writing. Output a combo card. Do not dump this protocol into the spoken script.

Evidence grades: R replicated finding; T tradition; D deduction from this skill; A inference when they named no school.
When grades conflict, prefer R for the act, T for induction style, D for dose, A only to break a tie.

## 4. Legal combo

school + induction + optional fraction ×2 + ONE primary engine + optional submod + scene-1 two-camera + ONE base PHS + optional ONE advanced PHS + Milton cap + ending.

Metaphor *or* parts in 20 minutes, not both. Elman depth then Ericksonian work is legal.

## 5. Score

+3 archetype fit; +2 legal stack; +2 ending matches; +1 channel exists; +1 named school; +1 two-second act; −3 illegal; −2 two engines; −2 sleep + tags/lids; −1 metaphor+parts+swish in 20 min.
Lock the higher score. Tie → shorter stack.
