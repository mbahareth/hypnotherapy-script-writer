# Post-Hypnotic Suggestion

A cue–act link that runs after the session. Install after change work and future pace, before emergence. Repeat the cue once in the close.

When [CUE that already happens], you already [ACT that takes two seconds], which means [IDENTITY or RESULT], for [WINDOW], and it can release when it no longer serves.

Good cues: first sip, phone unlock, hand on the door, sitting in the car before the key, opening the notebook, first foot on the floor, the desk chair.
Bad cues: whenever you need it, when stress comes, always, never again.

One primary cue. A second only as backup of the same act.

Acts a body finishes in two seconds: longer exhale, jaw unhook, both feet, finger and thumb, first word in the mouth, phone face-down, glass of water instead of the reach.
Not: become confident, heal, succeed, never crave.

Types: behavioral, somatic, cognitive, identity-after-behavior, recall, sleep-pillow-only.
Do not install amnesia-for-the-session as a default.
Same cue in future pace and PHS. Root form, not *if you happen to*.
