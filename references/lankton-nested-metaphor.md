# Lankton Nested / Multiple Embedded Metaphor

Protocol shape from Lankton & Lankton, rewritten as a production spine. Do not paste their transcripts. Do not say "Lankton" in the spoken file.

## When to use (optional, not a default)

Use the nest **only if** they asked for nested / multiple / Lankton / embedded stories **or** they asked for this protocol by name.

Duration is **not locked at 40:00**.

| Asked minutes | What to write |
|---|---|
| Under 30 | **No nest.** One goal-story from `goal-metaphor-engine.md` + Link + PHS |
| 30–45 | Full nest, **scale the clock** to their length |
| They said "40 min" | Use the 40:00 column below |
| They said nest but gave no length | Default **32–35 min**, not 40 |

Sleep-onset: do not run this protocol. SLEEP-AFTER is allowed (fade after PHS).

## Order (open down, close up)

Induction → Story A MATCH (unfinished) → Story B RESOURCE (click) → CORE (60–90s named act) → Close B → Close A → Link → Future pace + PHS (`When CUE, already ACT`) → Ending

Never close A before B. Never leave a story open at emergence.

## Scaled clocks

| Block | 30:00 | 35:00 | 40:00 | 45:00 |
|---|---|---|---|---|
| Set + induction | 0–5 | 0–5 | 0–6 | 0–7 |
| Open A | 5–10 | 5–11 | 6–12 | 7–14 |
| Open B | 10–15 | 11–17 | 12–18 | 14–20 |
| CORE | 15–17 | 17–19 | 18–21 | 20–23 |
| Close B | 17–21 | 19–24 | 21–26 | 23–29 |
| Close A | 21–25 | 24–28 | 26–31 | 29–35 |
| Link + future pace | 25–27 | 28–31 | 31–35 | 35–39 |
| PHS | 27–28 | 31–33 | 35–37 | 39–42 |
| Ending | 28–30 | 33–35 | 37–40 | 42–45 |

CORE stays short. Extra minutes go to A/B closes and one today-scene, not a third fable.

## Anti-patterns

- Treating 40:00 as mandatory
- Nest in a 20-minute file
- Four stories
- CORE as a fourth plot
- Close A while B is open
- Match story that already solves itself
