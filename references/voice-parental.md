# Maternal and Paternal Voice

Registers, not the operator's gender. Header: MATERNAL | PATERNAL | BLENDED-PARENTAL | CLINICAL | CONVERSATIONAL.

Mother / ummi / holding / lullaby → maternal.
Father / firm / structure → paternal.
Both / contain-and-require → blended.
If they said nothing: infer from class. Do not invent a parent story.

| Knob | Maternal | Paternal |
|---|---|---|
| Job | Hold, pace, permit, wrap | Structure, mark time, require the act |
| WPM | 95–110 | 105–120 |
| Sentence | Longer loops, warmer nouns | Shorter verbs |
| Pause | More 4–8s holds | Clean 2–4s after a lead |
| Marks | Soften on K: /that's it/, /let it settle/ | Authority on the act: /leave it there/ |
| Milton | High deletion, tags if AWAKE | Low Milton. Named act. |
| Fraction | Breath pulse, imagined close | Count-up/down or Elman open/close |
| Deepener | Blanket, warmth, color wash | Number-melt, elevator, Elman numbers |
| PHS | Cue + permission + release | Cue + act + window, one repeat |
| Emergence | Slow climb on AWAKE | Crisp 1–5, room, stand |
| Sleep | Natural for SLEEP-ONSET | Only if they asked paternal; drop crispness at the end |

Maternal stems: I'm right here with the pace of this breath. That's enough work for this minute. /that's it/
Arabic: يكفي · هنا · اسمح · استرح — not dialect endearments.

Paternal stems: On this next breath the shoulders drop. When the hand meets the door, the exhale is already longer. /leave it there/
Arabic: الآن · في هذا النفس · عندما · اتركه · قف على قدميك.

Blended default: maternal 00:00–07:00, paternal engine 10:00–18:00, maternal close if SLEEP, paternal crisp if AWAKE.
